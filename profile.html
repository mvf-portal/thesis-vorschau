Thesis-Portal · Profile

Nachwuchs der Versorgungsforschung kennenlernen

Wer eine Arbeit im Portal hat, kann ein Profil anlegen und sich vorstellen. Für jede Gruppe legen die Studierenden einzeln fest, ob sie Kontakt wünschen: Hochschulen und Forschung, Arbeitgeber, Personalvermittlung oder Praxispartner.

So funktioniert der Kontakt: Nachrichten laufen über das Portal. Schreiben kann nur, wer zu einer freigegebenen Gruppe gehört. Die E-Mail-Adresse der Studierenden bleibt verborgen, bis sie antworten. Der Kontakt über das Portal ist kostenlos.

Eigenes Profil

Ihr Profil legen Sie beim Einreichen einer Arbeit an. Ändern oder löschen können Sie es jederzeit über einen persönlichen Link, den Sie sich per E-Mail schicken lassen.
